# BUG-006: A negative `limit` on the article list returns 500

| | |
|---|---|
| **Status** | Open |
| **Severity** | Low (a malformed query, not a normal user action) |
| **Priority** | P3 |
| **Found by** | API probe while building `api-tests/` |
| **Found on** | 2026-11-10 |
| **Component** | API `GET /api/articles` |

## Steps to reproduce
`GET /api/articles?limit=-1`

## Expected
**422**, like a non-numeric limit.

## Actual
**500** (unhandled server error).

## Evidence

| Request | Status |
|---|---|
| `?limit=abc` | 422 (correct) |
| `?limit=0` | 200 |
| `?limit=-1` | **500** |

## Automation
`api-tests/tests/test_articles.py::TestListArticles::test_a_negative_limit_is_rejected` (`xfail`, strict).
