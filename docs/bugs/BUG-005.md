# BUG-005: Registration accepts an invalid email address

| | |
|---|---|
| **Status** | Open |
| **Severity** | Medium (bad data gets in; the user can never receive email, and the frontend relies on the API to validate) |
| **Priority** | P2 |
| **Found by** | API probe while building `api-tests/` |
| **Found on** | 2026-11-10 |
| **Component** | API `POST /api/users` |

## Steps to reproduce
`POST /api/users` with `{"user":{"username":"u1","email":"not-an-email","password":"Passw0rd!123"}}`

## Expected
**422**, because the email is not a valid address.

## Actual
**200**. The account is created with email `not-an-email`.

## Evidence
`PUT /api/user` with `{"user":{"email":"nope"}}` is correctly rejected with **422**, so email validation exists on update but not on register.

## Automation
`api-tests/tests/test_users.py::TestRegistration::test_an_invalid_email_is_rejected` (`xfail`, strict).
