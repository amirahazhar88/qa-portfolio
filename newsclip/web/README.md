# newsclip-web

Frontend of **newsclip** (daily news app), the app under test for this QA portfolio.
Vue 3 + Pinia + Vite, adapted from the MIT-licensed [RealWorld Vue example](https://github.com/realworld-apps/vue-realworld-example-app).

```sh
npm install
cp .env.example .env.local   # points the app at the local API (http://localhost:3100/api)
npm run serve                # http://localhost:8080
```
